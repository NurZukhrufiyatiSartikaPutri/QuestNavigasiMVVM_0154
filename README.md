## Dokumentasi Hasil Running Aplikasi

### 1. Tampilan Form Isian

Berikut merupakan hasil running aplikasi **QuestNavigasiMVVM_0154** pada emulator Android. Halaman ini menampilkan formulir untuk memasukkan data pengguna, yang terdiri dari nama lengkap, pilihan jenis kelamin, dan alamat.

**Fitur yang ditampilkan:**
- **Nama Lengkap:** kolom untuk memasukkan nama pengguna.
- **Jenis Kelamin:** pilihan antara Laki-Laki dan Perempuan menggunakan radio button.
- **Alamat:** kolom untuk memasukkan alamat pengguna.
- **Submit:** tombol untuk mengirim data formulir dan melanjutkan ke halaman berikutnya.

### 2. Hasil Pengujian

Berdasarkan hasil running pada emulator, halaman formulir berhasil ditampilkan dengan komponen input dan pilihan jenis kelamin yang tersusun rapi. Data contoh telah dimasukkan untuk menguji tampilan formulir, dan pilihan jenis kelamin Perempuan terlihat dalam keadaan terpilih.

Tombol **Submit** disediakan untuk melanjutkan proses navigasi ke halaman detail data.
